# DevDocs project guide

Read these documents before changing the application:

1. [Architecture](architecture.md) — target stack, boundaries, and routes.
2. [Schema](schema.md) — the planned application-owned database design.
3. [Rules](rules.md) — constraints for people and AI coding tools.
4. [Migration plan](migration-plan.md) — small, ordered milestones and their completion checks.

The current application is a React/Vite client backed by Supabase. These documents describe the intended migration to a Next.js application with application-owned authentication and database access. They are planning documents, not evidence that the migration has already happened.
